# 📋 Política de Privacidade - TradLibras

*Última atualização: Janeiro de 2024*

## 🎯 Introdução

O TradLibras está comprometido com a proteção da privacidade e dos dados pessoais de nossos usuários, em conformidade com a **Lei Geral de Proteção de Dados (LGPD)** e melhores práticas internacionais de privacidade.

Esta política explica como coletamos, usamos, armazenamos e protegemos suas informações quando você usa nossos serviços de tradução para Libras.

## 📊 Dados Coletados

### Dados Fornecidos Voluntariamente
- ✅ **Texto para tradução**: Frases e palavras inseridas para conversão
- ✅ **Áudio gravado**: Quando usa reconhecimento de voz (temporário)
- ✅ **Preferências de uso**: Configurações de interface e velocidade
- ✅ **Dados de contato**: Apenas se entrar em contato conosco

### Dados Coletados Automaticamente
- ✅ **Dados técnicos**: IP, navegador, dispositivo (anonimizados)
- ✅ **Dados de uso**: Páginas visitadas, tempo de sessão (agregados)
- ✅ **Logs de erro**: Para melhorar o serviço (sem dados pessoais)

### ❌ Dados que NÃO Coletamos
- ❌ Informações pessoais identificáveis sem consentimento
- ❌ Dados sensíveis (saúde, orientação sexual, crenças)
- ❌ Histórico de navegação em outros sites
- ❌ Dados de localização precisa

## 🎯 Finalidades do Processamento

### Base Legal (LGPD Art. 7º)
Nossa coleta de dados se baseia em:

1. **Consentimento** (inciso I)
   - Gravação de áudio para ASR
   - Cookies não essenciais
   - Newsletter (quando implementada)

2. **Execução de contrato** (inciso V)
   - Prestação do serviço de tradução
   - Suporte técnico

3. **Legítimo interesse** (inciso IX)
   - Melhoria do serviço
   - Prevenção de fraudes
   - Analytics agregados

4. **Exercício de direitos** (inciso VI)
   - Defesa em processos
   - Cumprimento de obrigações legais

### Uso dos Dados

#### ✅ Permitido
- **Tradução**: Processar texto/áudio para gerar sinais
- **Melhoria**: Aprimorar algoritmos (dados anonimizados)
- **Suporte**: Resolver problemas técnicos
- **Segurança**: Prevenir uso malicioso
- **Compliance**: Cumprir obrigações legais

#### ❌ Proibido
- Venda para terceiros
- Marketing não autorizado
- Profiling discriminatório
- Uso para outros fins não informados

## 🔒 Segurança e Proteção

### Medidas Técnicas
```
🔐 Criptografia
├── Em trânsito: HTTPS/TLS 1.3
├── Em repouso: AES-256
└── Chaves: Rotação automática

🛡️ Acesso
├── Autenticação: MFA obrigatória
├── Autorização: Princípio do menor privilégio
└── Auditoria: Logs de acesso

🔍 Monitoramento
├── Detecção: Atividades suspeitas
├── Alertas: Incidents automáticos
└── Resposta: Plano de incident response
```

### Medidas Organizacionais
- 👥 **Treinamento**: Equipe treinada em LGPD
- 📋 **Processos**: Procedimentos documentados
- 🔍 **Auditoria**: Revisões periódicas
- 🚨 **Incident Response**: Plano de resposta a vazamentos

### Retenção de Dados
| Tipo de Dado | Período de Retenção | Base Legal |
|--------------|-------------------|------------|
| Áudio gravado | 24 horas | Consentimento |
| Texto traduzido | 30 dias (anonimizado) | Legítimo interesse |
| Logs de uso | 12 meses (agregados) | Legítimo interesse |
| Dados de suporte | 2 anos | Exercício de direitos |

### 📋 Informação e Acesso

### ✏️ Modificação e Controle

## 🚨 Incident Response

### Em caso de vazamento de dados
1. **Detecção**: Sistema automatizado + equipe de segurança
2. **Contenção**: Isolar e parar o vazamento (máximo 1 hora)
3. **Avaliação**: Avaliar impacto e risco (máximo 24 horas)
4. **Notificação**: 
   - ANPD: 72 horas se alto risco
   - Usuários: Imediatamente se dados sensíveis
5. **Remediação**: Corrigir vulnerabilidade e melhorar segurança

## 📝 Glossário

- **ANPD**: Autoridade Nacional de Proteção de Dados
- **ASR**: Automatic Speech Recognition (Reconhecimento de Fala)
- **DPA**: Data Processing Agreement
- **LGPD**: Lei Geral de Proteção de Dados (Lei 13.709/2018)
- **SCCs**: Standard Contractual Clauses
- **Titular**: Pessoa física a quem se referem os dados pessoais
